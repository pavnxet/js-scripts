# js-scripts

A small collection of browser and JavaScript utility scripts.

## Repository structure

This repository is organized so more scripts can be added over time:

- `/scripts` — root folder for all scripts
  - `/scripts/reddit` — Reddit-focused scripts

Add new scripts by creating a focused subfolder under `/scripts` and placing each script in its own `.js` file.

## Included scripts

- `/home/runner/work/js-scripts/js-scripts/scripts/reddit/ultimate-reddit-extractor.js`  
  Extracts post + comments data from a Reddit thread page and downloads it as JSON.
